# F1 Race Simulator V2 - Project Report

## Introduction
F1 Race Simulator V2 is an educational Python application simulating qualifying and a Grand Prix with simplified strategy and reliability models.

## Objectives
1. Demonstrate modular Python programming.
2. Apply data structures and persistence.
3. Simulate Q1/Q2/Q3 and race conditions.
4. Calculate driver and constructor standings.
5. Demonstrate CRUD and file handling.

## Methodology
Driver data is loaded first. Qualifying produces the grid through Q1, Q2 and Q3. The race engine simulates laps, tyre ageing, pit stops, weather, Safety Car periods and mechanical reliability. The final classification generates championship points.

## Limitations
The model is simplified and does not reproduce official F1 telemetry or physics.

## Conclusion
The project combines multiple Python concepts into a larger modular simulation with persistent data and a realistic command-line workflow.
